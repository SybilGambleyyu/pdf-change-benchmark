# PDF Change Assurance Benchmark

PDF Change Assurance Benchmark, or PDFCAB, is a reproducible set of paired,
synthetic PDFs for evaluating static change-assurance tools. Every pair changes
one declared stored surface: actions, embedded files, forms, annotations, XFA,
portfolio structure, optional-content topology, signature dictionaries,
Associated Files, metadata presence, encryption, or incremental revisions.

The fixtures are not real documents. They contain blank pages and inert,
synthetic marker material. Public truth files disclose only a fixture ID,
category, generic description, and expected public change or policy IDs. They
never disclose JavaScript, URLs, attachment names or bytes, field names or
values, certificate material, passwords, metadata values, or hashes.

## Why it exists

Rendered and text-only PDF comparisons do not establish whether a handoff
gained a stored action, attachment, form, revision chain, or other non-page
surface. PDFCAB gives tools a small, versioned proof set for those boundaries.
It is intended for static analysis, not for claiming visual equivalence,
malware safety, signature validity, or viewer behavior.

Version 1.9 contains 91 fixture pairs spanning active content, embedded
content, interactive features, optional-content topology, Associated Files,
signature structure, metadata, encryption, and revision-chain evidence. It
adds GoTo3DView coverage for a document-action root and semantic action-chain
member. The positives rebind a page-attached 3D annotation or rewrite its
selected view while retaining public action inventory. The target-rebind cases
deliberately omit the annotation's optional /P page reference and make both
target objects otherwise indistinguishable; adapters must bind membership in
the page tree and Annots array rather than recurse into annotation contents.
The paired metadata and page-rotation negatives require only a stored-byte
change. The release retains SetOCGState, PDF 2.0 GoToDp, remote-GoTo, local
structure-destination, direct-navigation, and action-chain regressions.

## Install

    python -m pip install pdf-change-benchmark

## Use

Verify packaged fixture bytes and truth contracts:

    pdfcab verify

Score a PDFFence executable against the included fixture set:

    pdfcab score --pdffence pdffence

Build a fresh copy of the fixture set into an empty directory:

    pdfcab build generated-fixtures

The generator pins pypdf 6.15.0 because generated bytes are part of the
benchmark contract. See docs/ for fixture and scoring boundaries.

## Scope

PDFCAB invokes a supplied executable in a child process. It does not execute
PDF actions, open a PDF viewer, resolve a URI, decrypt a document, render a
page, inspect payload contents, or send fixtures over the network.
